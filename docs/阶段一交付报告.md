### 主动转向四驱逐关节诊断

本轮逐关节 DIRECT 诊断在平地接触下执行 `v=0.4 m/s`、`w=0.6 rad/s` 共 360 步。驱动关节按前左、前右、后左、后右固定排序：`front_left_drive_wheel_joint`、`front_right_drive_wheel_joint`、`rear_left_drive_wheel_joint`、`rear_right_drive_wheel_joint`。`p.getJointState(...)[1]` 读取的实际轮速约为 `3.3386 / 4.0000 / 4.0000 / 4.0002 rad/s`。最后一步 `p.getJointState(...)[3]` 的电机施加扭矩约为 `5.0000 / 0.0009 / -0.0066 / -2.0470 Nm`。四驱依据是四个独立驱动关节均处于速度控制且实际轮速均非零。`0.0009 Nm` 和 `-0.0066 Nm` 接近零，只记录为该步读数；逐轮扭矩会受转弯和接触载荷影响。

从仓库根目录执行以下命令可复现该诊断：

```bash
conda run -n slope-sim --no-capture-output python - <<'PY'
import pybullet as p

from slope_sim.model_registry import get_robot_model
from slope_sim.robot import create_robot
from slope_sim.scene import create_slope_scene

time_step = 1.0 / 240.0
client_id = p.connect(p.DIRECT)
try:
    scene = create_slope_scene(client_id, slope_deg=0.0, time_step=time_step, terrain_model="flat")
    spec = get_robot_model("active_steering_4wd")
    robot = create_robot(
        client_id,
        "active_steering_4wd",
        start_x=scene.spawn_position[0],
        start_y=scene.spawn_position[1],
        base_height=scene.spawn_position[2] + spec.base_height,
        start_orientation=scene.spawn_orientation,
    )
    robot.apply_drive_friction(lateral_friction=1.4, support_lateral_friction=0.03)

    for _ in range(120):
        robot.command_twist(0.0, 0.0, dt=time_step)
        p.stepSimulation(physicsClientId=client_id)
    for _ in range(360):
        robot.command_twist(0.4, 0.6, dt=time_step)
        p.stepSimulation(physicsClientId=client_id)

    labels = ("front_left", "front_right", "rear_left", "rear_right")
    for label, joint_name in zip(labels, spec.drive_joint_names):
        joint_state = p.getJointState(
            robot.robot_id,
            robot.joint_name_to_index[joint_name],
            physicsClientId=client_id,
        )
        print(
            f"{label} {joint_name}: "
            f"getJointState()[1]={joint_state[1]:.4f} rad/s "
            f"getJointState()[3]={joint_state[3]:.4f} Nm"
        )
finally:
    p.disconnect(client_id)
PY
```

## 4. GUI 启动方式

先进入项目环境：

```bash
conda activate slope-sim
```

前驱差速车和平面：

```bash
python main.py --gui --manual --drive-model physics --robot-model df_front --terrain-model flat
```

中驱差速车和 8 度斜面：

```bash
python main.py --gui --manual --drive-model physics --robot-model df_mid --terrain-model slope --slope-deg 8
```

后驱差速车和高尔夫起伏：

```bash
python main.py --gui --manual --drive-model physics --robot-model df_back --terrain-model golf_heightfield --golf-seed 41 --golf-relief medium
```

主动转向四驱和高尔夫起伏：

```bash
python main.py --gui --manual --drive-model physics --robot-model active_steering_4wd --terrain-model golf_heightfield --golf-seed 41 --golf-relief medium
```

方向键控制运动，空格停车，Dashboard 的“复位车辆”重新投放当前车型，`q`、`Esc` 或“退出”按钮结束。手动模式不会因为配置里的 `duration_sec` 自动结束。

启动任意组合后，可在 Dashboard 中：

1. 选择目标车型，点击“应用车型”；当前场地保持不变。
2. 选择目标场地；斜面填写坡度，高尔夫场地填写随机种子和起伏等级。
3. 点击“应用场地”；程序清零命令、重建场地，并把当前车型放到新场地安全出生点。
4. 观察“切换状态”；失败时程序自动恢复上一个有效世界。

只改变下拉框不会立即切换。场地重建后 CSV 会继续写入同一会话，但实时曲线会清空，避免连接两个世界的坐标。

相机验收：Dashboard 的“启用跟随”不需要“应用”按钮。打开后，“车后”和“侧面”会随车头旋转；“固定”只随车辆位置移动。关闭后用 PyBullet 鼠标调整相机，下一物理帧不应重置视角。

## 5. 用户 GUI 人工验收清单

- `df_front`：前轮驱动位置、后支撑轮接地、直行和差速转向是否自然。
- `df_mid`：中置驱动轮、前后支撑轮、坡面和起伏上的俯仰与驱动接触是否稳定。
- `df_back`：后轮驱动位置、前支撑轮接地、加减速俯仰是否合理。
- `active_steering_4wd`：四轮均参与驱动，两个前轮转向方向、限位和回正是否正确；Dashboard 的 4 轮速和 2 转角是否变化。
- `flat`：静止时无明显自移动、横漂、穿地或悬空。
- `slope`：正坡度时，车辆从高位平地沿 `+X` 依次进入下坡和低位平地；坡度与碰撞面一致，入坡和出坡姿态合理。
- `golf_heightfield`：多尺度丘陵、浅洼、横坡和驾驶廊道连续，无明显尖峰或台阶；同一 `golf_seed` 和 `golf_relief` 可复现。廊道保留大部分丘洼，不是直线平路。
- 四车型的外观比例、车体高度、轮距、轮径和传感器安装预留位置符合预期。
- 点击“复位车辆”后命令归零，旧车体消失并在当前场地出生点重新落地。
- 只改变车型或场地下拉框但不点击应用时，PyBullet 世界保持不变。
- 依次点击“应用车型”切换四种车型，确认场地不变、旧车消失、反馈车型同步更新。
- 依次点击“应用场地”切换三种场地，确认当前车型在新场地安全出生点重新出现。
- 修改斜面坡度和高尔夫种子/起伏后重新应用，确认参数生效且相同高尔夫参数可以复现。
- 每次切换后重新驾驶、复位和观察相机，确认控制链路仍然有效。
- 切换“启用跟随”并依次选择车后、侧面、固定；转弯时确认车后和侧面随车头旋转，固定视角只跟随位置。

用户可自行决定每项观察时长，不设置倒计时。

## 6. 已知限制和重点风险

- 当前执行环境是 SSH/TTY，`DISPLAY` 未设置，因此开发方未在本轮打开真实 PyBullet GUI；Qt 控件链路通过无界面自动测试，视觉效果和驾驶手感必须由用户在桌面会话中确认。
- 前驱和后驱差速车的驱动轴偏离车体几何中心，差速转向时车体中心会绕驱动轴形成小圆弧；这是前/后驱布局的物理结果，需要用户判断观感是否符合预期。
- 主动转向的底层接口支持两个前轮独立转向速度；GUI 的 `v/w` 便捷控制目前给两个前轮相同目标角，不模拟严格 Ackermann 内外轮角差。
- 高尔夫场地是硬质连续 heightfield，不模拟草叶、湿地、软土和轮胎下陷。
- 当前简化 LiDAR 和诊断字段不是最终企业接口；正式前后多线点云、RTK、IMU、eCAL 和 Dashboard 字段收敛留在阶段三。

当前已停止在阶段一补充交付门禁，等待用户 GUI 人工验收和反馈。在用户明确确认阶段一通过并提出“开始阶段二”之前，不实施障碍物等剩余阶段二功能。
