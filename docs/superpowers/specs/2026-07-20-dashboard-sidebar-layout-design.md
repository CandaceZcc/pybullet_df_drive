# Dashboard 固定侧边栏布局设计

## 目标

将阶段一 Dashboard 从宽屏主窗口改成固定侧边栏，消除横向控制条导致的窗口放大和图表缩放异常，同时保留全部遥测、图表、车型、场地、相机与驾驶功能。

## 窗口尺寸

- 窗口宽度固定为 `420` 个 Qt 逻辑像素，用户缩放不能改变宽度。
- 窗口高度在启动时取当前屏幕可用高度的 `95%` 并固定，避免覆盖任务栏、超出桌面或在运行中拖坏上下比例。
- 不再使用屏幕宽度百分比计算 Dashboard 宽度，也不再由横向控制条的 `minimumSizeHint()` 扩大窗口。

## 布局

Dashboard 使用单列上下分区：

1. 顶部显示现有“数据、轨迹、速度/命令、打滑、接触”标签页，目标占可用内容高度的 `45%`，并优先保留 `320 px` 最小高度。
2. 图表画布始终留在顶部，不随下方参数滚动。Matplotlib 边距按窄画布调整，完整显示标题、坐标轴标签、图例以及“清空曲线、保存当前图”按钮。
3. 下方使用一个纵向 `QScrollArea`，获得扣除标题和顶部标签页后的全部剩余高度；内容超出时只滚动该区域。
4. 滚动内容按“参数、车型、场地、相机、控制”顺序纵向排列；所有输入框、按钮和状态文本保持可达。
5. “数据”页继续使用自己的遥测滚动区，避免大量字段压缩顶部标签页。

## 行为保持

- 不修改速度命令、键盘事件、按钮脉冲、车型/场地事务切换、相机跟随、曲线刷新和保存逻辑。
- 只改变窗口尺寸计算、控件排列方向和布局尺寸约束。
- 场地参数仍根据当前场地启用或禁用；切换状态和错误信息仍在场地组内显示。

## 验收与测试

- 尺寸函数在常见和小型屏幕上都返回 `420 px` 宽及不超过可用高度 `95%` 的高度。
- Qt 离屏测试确认窗口宽度固定，参数区存在垂直滚动条，五个控制组按纵向顺序排列且均位于滚动内容中。
- 顶部标签页和当前图表画布不在参数滚动区内；窄侧栏下图表按钮、坐标轴和标签不被裁切。
- 现有 Dashboard、手动驾驶、车型/场地切换和全量测试继续通过。
- 最后在真实桌面会话中启动 PyBullet GUI，人工确认 Dashboard 与仿真窗口可以并排使用。

## 非目标

- 不把 Dashboard 嵌入 PyBullet 原生窗口；PyBullet 和 PySide6 仍是两个独立窗口。
- 不新增车型、场地、遥测字段或阶段二功能。
- 不改变 Dashboard 的视觉主题或控制语义。
